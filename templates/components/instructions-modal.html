ℹ️ Instructions

Welcome to P.A.C.K. (Pairwise Analysis and Cleanup Kit)! This tool groups on e621 so you can quickly fix relationships (like parent/child variants or pools), merge tags, and resolve duplicate uploads.

Work is organized into projects built around specific search criteria. Each project presents groups of related posts as clusters that need attention.

Getting Started & API Login

Click Start Comparison on any cluster and P.A.C.K.'s interfaces will guide you step-by-step through reconciling metadata, merging tags, and flagging inferior duplicates.

To submit resolution actions and apply your changes to e621, log in with your username and API key using the API Login button in the header.

Claiming & Reviewing Batches

Claiming a batch reserves it for 1 hour (limit one batch per user) so others know you're working on it. Claimed batches still remain viewable by everyone.

You don't have to finish every cluster in a batch. Skip anything you don't want to review, and click Release Batch whenever you're done so the remaining clusters are available for others.

Syncing Progress

Post data updates automatically in the background. If you want your recent edits (tags, ratings, or relationships) to show up immediately, click Refresh Batch, or release the batch when finished.
